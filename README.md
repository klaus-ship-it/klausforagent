# Yota 代理後台原型

這是 Yota 專案獨立的代理後台 prototype，與 `Yota_operations_main`（營運後台）分開維護。本資料夾是完整原始碼，可直接以 VS Code / GitHub Desktop 開啟。

## 已涵蓋的第一版範圍

- 代理登入與總覽儀表板
- 代理樹狀關係、直屬／全部下級切換、代理狀態啟停
- 代理建立（新代理立即啟用）與反傭比例展示
- 玩家資料唯讀、隱私遮罩提示
- 直屬代理／直屬玩家推廣碼分流
- 佔成／返佣傭金摘要、明細、提領申請與審核狀態
- 下級報表（樹狀路徑、層級、直屬／全部切換）
- 代理後台操作日誌
- 運營商管理代理 Google Auth 2FA（重設與重新綁定 QR Code 示意）

## 本機預覽

```bash
pnpm install
pnpm dev
```

原型登入頁接受任意非空白帳號與密碼。這一版為產品討論用的 mock prototype，不連接真實資料或支付服務。
